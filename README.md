# Niqat / ንቃት
## A platform that protects Ethiopia's payment system by checking for fraud, analyzing patterns & warning users

##### Niqat is an app that protects and helps the users identify fraud and scammers in order to protect the loss beforehand. it is also  used to collect data for the law society and help scammers get in front of law and make sure they face consequences. it can be integrated in to Ethswitch and Telebirr. so that the digital money management in Ethiopia can be safe and sound.
